# MCP 服务器插件（输出与调试）

为 Android Code Studio 增加了 **MCP (Model Context Protocol) 服务器插件**，
把整个 IDE 与当前项目软件的能力开放给外部 AI 客户端（Cursor / Cline / VS Code / mcp-remote 等）。

- 位置：`external/plugins/McpServer`
- 形态：标准 ACSIDE 插件（`.acp`），由官方 `io.github.nullij.acside-gradle-plugin:0.2.0` 打包
- 云端构建：`.github/workflows/mcp-plugin.yml`（GitHub Actions，产物 `McpServer.acp`）

## 新增能力

- **输出与调试面板**：三页签控制台（输出 / 调试 / MCP 设置）。显示监听状态、endpoint、
  实时 JSON-RPC 日志、工具调用历史、按分组的工具覆盖表、本机 socket 回环自检结果。
- **独立设置**：`<filesDir>/acs-mcp/settings.json`（普通 JSON，可在 IDE 里直接编辑）。
  可单独设置：启用开关、自动监听、面板自启、端口、绑定网卡、Bearer Token 认证、
  只读安全模式、日志级别与保留行数、IDE 环境 shell、Gradle 命令、GRADLE_OPTS、
  宿主 shell、adb 命令、按分组的工具开关、允许/拒绝清单。
- **覆盖整个项目软件的 MCP 工具**（9 组 / 40 个工具）：
  `ide` `project` `file` `build` `deploy` `shell` `editor` `lsp` `mcp`。

## 说明

ACSIDE 本体是闭源的（见根 README「About the Source Code」），因此本功能以官方插件形态实现，
不修改 IDE 自身代码；插件只使用 `PluginApi` 暴露的 editor / environment / lsp / templates /
process / ui 六类能力，Compose 与插件 API 全部 `compileOnly`，不在 plugin.apk 里重复打包。
